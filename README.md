# 🤖 KiberBot — Автоматизация начисления бонусов

Привет! 👋 Этот проект создан для автоматического анализа посещаемости учеников и массового начисления им бонусов через API CRM KiberOne.

## ⚠️ ВАЖНО: Первый шаг перед запуском

1.  Найди в корне проекта файл **`job.example.json`**.
2.  Переименуй его в **`job.json`** (просто удали слово `.example`).
3.  Открой `job.json` и заполни свои данные:
    *   `API_KEY` и `email` для получения токена.
    *   `amount` (сумма бонуса) и `note` (комментарий к начислению).
    *   `names_tutors` — имена преподавателей из CRM, чьи группы нужно проверить, в формате
    ("Иванов Иван ", "Петров Андрей").
    *   `date_from` и `date_to` — период, за который проверяется посещаемость.

## 🛠 Установка Go 1.25.6

Для работы проекта требуется версия Go **1.25.6**. Если у тебя её еще нет, следуй инструкции:

### Для Windows 10/11:
1.  Перейди на официальный сайт [go.dev/dl](https://go.dev/dl/).
2.  Скачай установщик **Go 1.25.6** для Windows (файл `.msi`).
3.  Запусти установщик и следуй инструкциям (по умолчанию он установится в `C:\Go`).
4.  После установки открой командную строку (cmd) или PowerShell и проверь версию:
    ```bash
    go version
    ```
    Ты должен увидеть: `go version go1.25.6 windows/amd64`.

### Для macOS / Linux:
Если ты используешь менеджер версий `gvm` или `asdf`, просто выполни:
```bash
gvm install go1.25.6
gvm use go1.25.6
```
Или скачай архив с [официального сайта](https://go.dev/dl/) и распакуй его в `/usr/local/go`.

## 🚀 Запуск проекта

1.  Убедись, что у тебя установлен Go 1.25.6.
2.  Открой терминал в папке проекта `D:\kiberbot`.
3.  Скачай зависимости:
    ```bash
    go mod tidy
    ```
4.  Запусти бота:
    ```bash
    cd D:\kiberbot
    go run ./main/
    ```

## 📂 Структура проекта

*   `config/` — работа с конфигом и получение токена авторизации 🔑.
*   `transport/customers/` — логика проверки посещаемости и начисления бонусов 💰.
*   `transport/groups/` — парсинг данных о группах и преподавателях 👥.
*   `transport/teacher/` — поиск ID преподавателя по имени 🕵️‍♂️.

## ⚙️ Как это работает?

1.  Бот загружает настройки из `job.json`.
2.  Получает токен доступа через API.
3.  Находит ID преподавателя по имени.
4.  Выгружает список групп этого преподавателя.
5.  Для каждой группы проверяет посещаемость учеников за указанный период.
6.  Начисляет бонусы тем, кто не пропустил ни одного занятия! 🎉
